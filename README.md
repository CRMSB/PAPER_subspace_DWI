# Subspace_DWI.jl

Julia implementation of subspace reconstruction for accelerated high-resolution diffusion-weighted MRI.

This repository contains the reconstruction framework developed for accelerated 3D diffusion MRI of the ex vivo mouse brain. The method exploits the redundancy across diffusion volumes by representing the diffusion signal in a low-dimensional subspace.

Two strategies are implemented to estimate the subspace basis:

* **Simulation-based basis**: generated from a dictionary of diffusion tensor signals with different eigenvalues and orientations.
* **Calibration-based basis**: estimated directly from the fully sampled central region of k-space.

The subspace reconstruction is performed with the Berkeley Advanced Reconstruction Toolbox (BART) using wavelet regularization.

---

## Overview

The reconstruction pipeline includes:

1. Reading Bruker diffusion MRI acquisitions.
2. Conversion of the acquisition to the reconstruction format.
3. Initial reconstruction for phase estimation.
4. Correction of inter-volume phase variations.
5. Generation or calibration of the subspace basis.
6. Coil sensitivity estimation.
7. Subspace reconstruction using BART.
8. Projection of the reconstructed subspace coefficients back into the diffusion-volume domain.

## Simulation-based subspace basis

The simulation-based approach generates a dictionary of diffusion-weighted signals using the diffusion tensor model:

$$
S(\mathbf{g}) = S_0 \exp\left(-b\,\mathbf{g}^{T}D\mathbf{g}\right)
$$

where \(D\) is the diffusion tensor and \(\mathbf{g}\) is the diffusion gradient direction.

A set of diffusion tensors is generated by varying:

* the tensor eigenvalues;
* the principal diffusion direction over a hemisphere;
* the orientation of the secondary eigenvectors around the principal axis.

For each simulated tensor:

$$
D = V \Lambda V^{T}
$$

where \(\Lambda\) contains the tensor eigenvalues and \(V\) contains the corresponding eigenvectors.

The simulated signal dictionary is decomposed using singular value decomposition (SVD), and the dominant right singular vectors are retained to construct the temporal subspace basis.

### Example

```julia
basis = build_basis(
    bruker_path,
    n_bases,
    n_angles,
    b_value,
    lambda_min,
    lambda_step,
    lambda_max,
    subspace_dim,
)
```

where:

* `n_bases` controls the number of principal diffusion directions;
* `n_angles` controls the number of orientations around each principal direction;
* `lambda_min`, `lambda_step`, and `lambda_max` define the sampling of tensor eigenvalues;
* `subspace_dim` defines the number of retained basis vectors.

## Calibration-based subspace basis

The calibration-based approach estimates the temporal subspace directly from the acquisition.

A fully sampled central region of k-space is extracted and reconstructed at low spatial resolution. The resulting diffusion volumes are then used to estimate the dominant temporal components through singular value decomposition.

The spatial extent of the calibration region is controlled by `center_size`.

Example:

```julia
subspace_coefficients, reconstructed_images =
    subspace_reconstruction_calibration(
        bruker_path,
        center_size,
        n_basis,
        iterations,
        regularization,
    )
```

---

## Simulation-based reconstruction

A simulated basis can be supplied directly to the reconstruction:

```julia
subspace_coefficients, reconstructed_images =
    subspace_reconstruction_simulation(
        bruker_path,
        basis,
        iterations,
        regularization,
    )
```

The reconstruction is performed in the reduced subspace domain using BART PICS with spatial wavelet regularization.

The reconstructed subspace coefficients are subsequently projected back into the original diffusion-volume domain.

---

## Phase correction

A global phase correction is applied across diffusion volumes before subspace reconstruction.

The phase difference between each diffusion volume and the reference volume is estimated from a reference voxel located arbitrarily at the center of the reconstructed volume. The corresponding phase offset is then removed from the k-space data.

This reference selection provides a simple initial strategy for compensating for inter-volume phase variations. Its robustness should nevertheless be further evaluated, and a more dedicated phase-estimation method could be implemented in future developments.

---

## BART reconstruction

The subspace reconstruction relies on the BART PICS framework.

The current reconstruction uses wavelet regularization with:

```text
pics -S -e -R W:7:0:<regularization>
```

The number of iterations and the regularization strength are specified by the user.

Coil sensitivity maps are estimated using BART `ecalib`.

---

## Outputs

The reconstruction functions return:

```julia
subspace_coefficients, reconstructed_images
```

where:

* `subspace_coefficients` contains the reconstructed coefficient images in the reduced subspace representation;
* `reconstructed_images` contains the diffusion volumes reconstructed in the original diffusion-volume domain.
